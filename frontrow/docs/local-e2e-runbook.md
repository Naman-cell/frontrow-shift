# Local E2E Runbook

## 1. Start Infrastructure

Start Docker Desktop, then run:

```bash
docker compose up -d
```

This starts:

- Postgres on `localhost:5432`
- Redis on `localhost:6379`

## 2. Create `.env`

Copy the example:

```bash
cp .env.example .env
```

Fill in:

```env
GEMINI_API_KEY=your_key_here
ENABLE_GEMINI=true
ENABLE_TTS=false
```

Turn on TTS only when you want audio responses:

```env
ENABLE_TTS=true
```

The interviewer voice is generated by Gemini TTS on the backend. The frontend
does not use browser `speechSynthesis`.

Default model choices:

```env
GEMINI_AUDIO_MODEL=gemini-2.5-flash
GEMINI_TTS_MODEL=gemini-3.1-flash-tts-preview
```

## 3. Sync Dependencies

Preferred:

```bash
uv sync
```

If `uv.lock` needs refreshing after dependency changes:

```bash
uv add haystack-ai google-genai redis sqlalchemy asyncpg
```

## 4. Run Tests

```bash
uv run pytest
RUFF_CACHE_DIR=/tmp/frontrow-ruff-cache uv run ruff check .
```

## 5. Run API

```bash
uv run uvicorn app.main:app --reload
```

## 6. Minimal REST Flow

Create interview:

```bash
curl -X POST http://localhost:8000/api/v1/interviews \
  -H 'content-type: application/json' \
  -d '{
    "tenant_id": "org_demo",
    "candidate_id": "candidate_demo",
    "duration_minutes": 20,
    "question_mode": "AI",
    "role": {
      "title": "Python Backend Engineer",
      "seniority": "mid",
      "job_description_summary": "Build FastAPI services, work with PostgreSQL and Redis, debug production systems, and deploy AI integrations.",
      "resume_summary": "Candidate has 3 years of backend experience with FastAPI, PostgreSQL, Redis, and AI model deployment.",
      "required_skills": ["Python concurrency", "API design", "PostgreSQL"]
    }
  }'
```

Start interview:

```bash
curl -X POST http://localhost:8000/api/v1/interviews/{interview_id}/start
```

Process a turn over REST:

```bash
curl -X POST http://localhost:8000/api/v1/interviews/{interview_id}/turn \
  -H 'content-type: application/json' \
  -d '{
    "text": "I am not sure, I do not know that Python topic well.",
    "user_leave": false,
    "overtime": false,
    "is_complete": false
  }'
```

Complete:

```bash
curl -X POST http://localhost:8000/api/v1/interviews/{interview_id}/complete
```

Fetch report:

```bash
curl http://localhost:8000/api/v1/interviews/{interview_id}/report
```

## 7. WebSocket

Connect to:

```text
ws://localhost:8000/api/v1/interviews/{interview_id}/ws
```

Inbound payload:

```json
{
  "text": "candidate answer text",
  "audio_ref": null,
  "audio_base64": null,
  "audio_mime_type": null,
  "user_leave": false,
  "overtime": false,
  "is_complete": false
}
```

## 8. Browser Frontend

A small static tester lives in:

```text
frontend/index.html
```

Run it with any static server:

```bash
python3 -m http.server 5173 -d frontend
```

Open:

```text
http://localhost:5173
```

Use **Create + Start**, then **Connect WS**, then answer through the chat box.
Use **Record** and **Stop** to submit the actual microphone audio to the backend.
When `ENABLE_GEMINI=true`, the Gemini audio model receives that audio payload for
answer analysis. The text box is now only a fallback/debug transcript field.

Outbound payload:

```json
{
  "query_asked": "question text",
  "completed": false,
  "interview_duration": 1200,
  "audio_base64": null,
  "audio_mime_type": null,
  "reconnect": {},
  "meta": {
    "question_mode": "AI",
    "turn_index": 1,
    "move_type": "switch_adjacent_topic",
    "target_skill": "api_design",
    "reason": "..."
  }
}
```
